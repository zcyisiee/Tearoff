# EdgeMark Markdown 大纲导航（对标 VSCode Outline）

## 已确认的设计决策
- **两种形态都做**，设置里「大纲位置」切换：右侧 = 垂直标题树面板；顶部 = 面包屑条。
- **默认开启**，编辑器页头有显隐开关按钮（状态持久化）。
- **滚动反向同步**：编辑器滚动时，大纲高亮当前所在标题，面包屑路径跟随。
- **首行 `# 笔记标题`**（被剥离显示在页头的那行）收录为大纲第一项，点击滚回顶部。
- 右侧面板：**节点可折叠**、**宽度可拖拽**；面包屑：**点击某级弹出该级下级标题**。

## 技术要点（基于代码摸底）
- 编辑器是引擎 `NativeTextViewWrapper`（NSTextView + TextKit 2），大纲数据直接从编辑器 `text` 做 O(n) 行扫描，无需碰引擎。
- 跳转/滚动同步需要拿到编辑器 `NSScrollView`：复用现有 `findEditorTextView(in:)` 模式（ImageDropHandler.swift:77），监听 scrollView `boundsDidChangeNotification`。标题 Y 坐标用 TextKit 2 `enumerateTextLayoutFragments`（引擎 find 模块同款路径，规避 `scrollRangeToVisible` 在 TextKit 2 下的坑）。
- 解析需跳过 ``` / ~~~ 围栏代码块内的 `#` 行，避免误判标题。

## 新增文件
1. `EdgeMark/Core/Editor/MarkdownOutline.swift` — `OutlineEntry`（level/title/range/pathKey）+ 围栏感知的行扫描解析器。
2. `EdgeMark/UI/Outline/OutlineState.swift` — `@Observable` 状态：entries、当前可见标题索引、折叠集合（会话内存，重启重置，键 = 层级路径字符串，抗编辑偏移）、跳转入口。
3. `EdgeMark/Core/Editor/OutlineScrollCoordinator.swift` — 定位并弱持有编辑器 NSScrollView/NSTextView，滚动监听 → 二分求可见顶部所属标题；执行跳转（fragment 级滚动，不抢焦点、不动光标）。
4. `EdgeMark/UI/Outline/OutlinePanelView.swift` — 右侧面板：缩进树、折叠箭头、当前行高亮、拖拽调宽手柄（宽 180–420pt，持久化）。
5. `EdgeMark/UI/Outline/OutlineBreadcrumbView.swift` — 顶部面包屑：当前标题路径 `H1 › H2 › H3`，点击某级弹出该级子标题 popover 列表，点选跳转。

## 修改文件
- `AppSettings.swift` — 新增 `OutlinePosition`（top/right，默认 right）、`outlineVisible`（默认 true）、`outlinePanelWidth`，UserDefaults 持久化，沿用现有 didSet/init 模式。
- `EditorScreen.swift` — 页头加大纲开关按钮（与 Pin/Copy/Delete 同排）；`outlinePosition == .top` 时在页头下插入面包屑条；`== .right` 时内容区改为 `HStack(编辑器 + 分隔线 + 大纲面板)`；创建并下发 `OutlineState`。
- `MarkdownEditorView.swift` — 接收可选 `outlineState`；在现有 `.onChange(of: text)` 里（仅当大纲可见时）重解析大纲；onAppear/onDisappear 挂载/卸载滚动协调器。
- `GeneralSettingsTab.swift` — 「编辑器」分区加大纲显示开关 + 位置 Picker（top/right），沿用现有写法。
- `Resources/Locales/*.json`（en/zh-Hans/de/es/hi）— 新增 `outline.*` 键，5 种语言都补翻译。

## 性能与克制
- 大纲解析是单遍行扫描，仅在 `text` 变化且大纲可见时执行；无防抖、无定时器。
- 滚动同步用监听事件驱动，不做轮询；不做多余空态/容错分支（无标题时显示一行占位文案即可）。
- Peek 预览窗、回收站只读预览**不**加大纲（只在主编辑器）。
