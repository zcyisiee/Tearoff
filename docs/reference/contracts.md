# 契约

当前行为（v5-tauri，2026-11-15 核对）。字段全集见 `src/lib/types.ts` 与 `src-tauri/src/{vault,finder,settings}.rs`；这里写责任与语义。

## 笔记库

- 库 = 用户选定的一个文件夹。默认 `~/Documents/Tearoff`（Windows：文档目录下 `Tearoff`）。在设置里更换；换库只是换指向，不搬文件。
- 笔记 = 库内任意深度（≤8 层）的 `.md` 文件。不列出：以 `.` 开头的目录、名为 `assets` 或 `node_modules` 的目录。
- **笔记的身份是库内相对路径**（`/` 分隔，如 `Daily/2026-11-15.md`）。标题 = 文件名去掉 `.md`。
- 今天的纸 = `Daily/<本地日期>.md`。`Daily/` 下文件名为 `YYYY-MM-DD` 的笔记都算日记纸（含旧版的 `Daily/Archive/`）。文件在第一次写入非空内容时才创建。
- 应用外重命名/移动一个笔记，它的固定状态和手动顺序会丢（按路径记的）。

### Sidecar：`<库>/.tearoff/v5.json`

```json
{ "version": 1,
  "notes": { "<相对路径>": { "pinned": true, "order": 0, "created": 1788249600000 } },
  "folderCards": [ { "id": "…", "favorites": [{ "id": "…", "path": "/abs", "name": "常用" }], "selectedFavorite": "…",
                     "currentPath": null, "viewMode": "list", "sortKey": "name", "sortAsc": true, "listHeight": 220, "order": 1 } ] }
```

- 只存文件自己存不了的东西；条目全为默认值或文件已不存在时会被清理。
- 首次打开一个没有 `v5.json` 但有旧版 `meta.json` 的库：导入固定、顺序、创建时间、文件夹卡片，然后只写 `v5.json`。`meta.json` 永不改写——旧版 Swift 应用可以继续用同一个库，两边的固定/顺序此后各管各的。
- 旧版的标签、颜色、应用内回收站（`.trash/`）不导入、不显示、不删除。

## 写入语义

| 行为 | 规则 |
|---|---|
| 写笔记 | 同目录临时文件 + rename。带 `baseModified` 时，磁盘 mtime 不等于它就失败并返回 `conflict`，文件不动 |
| 冲突处理（前端） | 磁盘内容等于上次所见 → 直接覆盖；否则磁盘版本留在原文件，用户版本写入 `<标题>（冲突副本 N）.md` |
| 打开笔记 | 不写盘。只有文档相对加载时的序列化结果发生变化才保存 |
| 序列化 | 输出以单个换行结尾；front matter 原样接回 |
| 新建笔记 | 库根目录，`未命名.md`、`未命名 2.md`… |
| 重命名 | 目标已存在返回 `exists:<标题>`；文件名非法字符被去掉 |
| 删除笔记、删除文件 | 移到系统废纸篓/回收站，应用不做永久删除 |
| 粘贴图片 | 存到笔记同目录 `assets/image-<时间>.<扩展名>`，正文插入相对路径 |
| 移动文件（文件夹卡片） | 整批预检：目标有同名返回 `exists:<名>`、不能移进自身；已在目标目录的跳过；跨卷退化为复制 + 原件进废纸篓 |

## 错误

命令失败时前端收到字符串。稳定的记号：`conflict`、`exists:<名>`、`notFound`、`invalid path`。其余是系统错误原文，直接展示给用户。

## 事件（后端 → 前端）

| 事件 | 负载 | 含义 |
|---|---|---|
| `vault-changed` | 无 | 库内有文件变化（250ms 聚合；忽略 `.tearoff/` 与临时文件）。前端重新 `get_state` |
| `dir-changed` | 目录绝对路径 | 某张文件夹卡片当前显示的目录有变化 |
| `panel-shown` | `bool`：是否应把键盘焦点给今天的纸 | 面板已显示。事件可能早于界面加载，界面启动时另查 `get_state().panelShown` |
| `panel-hidden` | 无 | 面板开始收起；前端立即 flush 所有保存器 |

## 面板行为

- 显示：贴住所选一侧屏幕边缘 ≥ `activationDelayMs`（且没按着鼠标键）→ 在光标所在显示器显示，**不取得键盘焦点**；快捷键或托盘 → 显示并聚焦今天的纸。
- 收起：光标进入过面板后离开超过 `hideDelayMs`；或面板失去键盘焦点；或 Esc；或再按快捷键。
- 不收起：已固定；忙（菜单、文件夹选择框、文件拖拽进行中）；鼠标键按着；光标还没进入过面板（仅针对“离开即收”）。
- macOS：因打字而成为活动应用时，收起后把活动状态还给之前的应用。

## 编辑器

- 快捷键：⌘B 加粗、⌘I 斜体、⌘⇧S 删除线、⌘⇧H 高亮、⌘E 行内代码、⌘K 链接、**⌘T 待办**、⌘⇧8 列表、⌘⇧7 编号、⌘⌥1/2/3 标题、⌘⇧B 引用、⌘⌥C 代码块（Windows 上 ⌘ 换 Ctrl）。输入 `/` 打开块菜单。Markdown 输入习惯（`- `、`# `、`[] `）仍然生效。
- 应用级：⌘N 新建、⌘F 搜索、⌘D 回到今天、⌘, 设置、Esc 逐级退出（展开 → 搜索/设置 → 收起面板）。⌘/Ctrl+点击链接在浏览器打开。
- 公式：`$…$`（紧贴定界符、后面不跟数字才算）与独占一段的 `$$…$$`，KaTeX 渲染，点击修改。
- 富文本不支持、因此会以原文模式打开的内容：行内/块级 HTML、脚注。Wiki 链接 `[[x]]` 会被当普通文本，保存时方括号会被转义。
